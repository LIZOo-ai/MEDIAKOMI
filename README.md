# Медиакоми — «Угадай цену квартиры»

Браузерная игра-приложение на основе реальных объявлений о продаже квартир в Республике Коми (г. Инта, Avito).

## Как играть

1. На главном экране нажмите **«Запуск игры»**.
2. Игра показывает 10 квартир по одной: фотографии (галерея со свайпом), тип квартиры, этаж, улица.
3. Двигайте бегунок и выставьте цену, которую считаете правильной, затем нажмите **«Оценить»**.
4. Вы увидите реальную цену, разницу (₽ и %), заработанные баллы и **ссылку на реальное объявление**.
5. После 10 лотов — итог: сумма баллов и архипетип игрока:
   - 😏 **Жадный студент** — стабильно называл цены ниже реальных (в среднем на 8% и более);
   - 🤝 **Адекватный квартирант** — оценки в основном совпадали с реальными ценами;
   - 💸 **Транжира** — как правило называл цены выше реальных (в среднем на 8% и более).

## Балльная система

- Максимум **100 баллов** за квартиру, **1000** за игру.
- Отклонение до 5% — 100 баллов; дальше −2 балла за каждый процент свыше 5%.
- Отклонение 55% и больше — 0 баллов.

## Технологии

- Чистые HTML/CSS/JS — без зависимостей и сборки.
- Мобильная версия в приоритете: один экран — одна карточка, свайп-галерея, адаптивная вёрстка.
- Цветовая схема в стиле [hse.ru](https://www.hse.ru) — #012D6E.
- Данные — `data.js`, сгенерированный из CSV объявлений (скрипт `generate_data.ps1`).

## Запуск

Откройте `index.html` в браузере, либо:

```bash
# любой статический сервер, например:
npx serve .
```

## Публикация на GitHub Pages

1. Создайте репозиторий и загрузите `index.html`, `data.js`, `README.md`.
2. Settings → Pages → Source: `main` / root.
3. Игра будет доступна по адресу `https://<username>.github.io/<repo>/`.

## Обновление данных

CSV с новыми объявлениями (колонки: ссылка, фото 1–5, цена, цена за м², описание, улица) положите рядом и выполните:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File generate_data.ps1
```

Скрипт берёт только активные объявления с минимум 2 фотографиями.
